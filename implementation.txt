# Implementation Plan - Balance Sheet Management System (MERN Stack)

Build a full-featured, enterprise-grade **Balance Sheet Management System** with double-entry accounting engine, interactive financial reporting (Balance Sheet, Profit & Loss, Cash Flow, Ledger), Chart of Accounts, Income & Expense management, Admin User Management, JWT authentication, and PDF/Excel export capabilities.

---

## Technical Stack & Architecture

### Backend Architecture (`backend/`)
- **Runtime**: Node.js & Express.js
- **Database**: MongoDB with Mongoose ORM
- **Auth & Security**: JWT (JSON Web Tokens), `bcryptjs` password hashing, CORS, `dotenv`, role-based middleware (`Admin`, `Accountant`, `User`)
- **Structure**:
  - `config/db.js`: Mongoose connection with error handling & auto-seeding default accounts and superadmin.
  - `models/`: User, Account, Transaction, Income, Expense, Notification schemas.
  - `controllers/`: Modular controllers for Auth, Accounts, Transactions, Income, Expense, Reports, Users, Notifications.
  - `middleware/`: `authMiddleware` (token validation), `roleMiddleware` (RBAC), `errorHandler` (centralized response formatter).
  - `services/`: Accounting calculations (Double-Entry Engine, Financial Statements calculations, Ledger generator).
  - `routes/`: Express REST API endpoints matching prompt requirements.

### Frontend Architecture (`frontend/`)
- **Framework & Tooling**: React.js (Vite), React Router DOM v6
- **Styling & UI**: Tailwind CSS, Lucide Icons, modern dark/light balanced theme with glassmorphism & responsive layouts.
- **Data Visualization**: Recharts (Income vs Expenses, Assets vs Liabilities, Monthly Revenue/Expense trend).
- **Exporting**: `jspdf` + `jspdf-autotable` for PDF generation, `xlsx` for Excel export, native window print styling.
- **State Management**: React Context (`AuthContext`, `NotificationContext`) + Axios instances with interceptors.

---

## User Review Required

> [!IMPORTANT]
> - **Default Database Credentials & Port**: Backend will listen on port `5000` (or `PORT` in `.env`) connecting to local MongoDB (`mongodb://127.0.0.1:27017/balancesheet`).

## Verification Plan

### Automated & Integration Tests
1. Test MongoDB Connection & Schema Initialization.
2. Test User Registration, Password Hashing, JWT Login, and RBAC permissions.
3. Test Double-Entry Transaction Engine:
   - Verify creation fails if `Total Debit !== Total Credit`.
   - Verify transaction updates account balances correctly (Debit increases Asset/Expense, Credit increases Liability/Equity/Revenue).
4. Verify Balance Sheet logic:
   - Ensure `Assets = Liabilities + Equity` holds true for all test accounting data.
   - Verify Net Profit calculation rolls into Retained Earnings / Current Profit in Balance Sheet.

### Manual & Visual Verification
1. Start both backend server (`http://localhost:5000`) and frontend Vite dev server (`http://localhost:5173`).
2. Log in as default Admin user (`admin@balancesheet.com` / `admin123`).
3. Add accounts, create income & expense entries, verify real-time dashboard update and Recharts graphs.
4. Export Balance Sheet, Profit & Loss, and Cash Flow statements to PDF and Excel.
